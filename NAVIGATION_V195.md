# Эталонная навигация · v195

Панель уже установлена на всех 11 страницах проектов. Главная страница, её стили и скрипты сохранены без изменений относительно v194.

## Источники

Из Whoosh v194 перенесены состав и расположение элементов, размеры, отступы, цвета, прозрачность, размытие и обычные состояния панели. На десктопе ширина панели — до 960px, высота контейнера — 63px, кнопки разделов — одинаковой высоты 38px.

Из Travel v194 перенесены эффективные параметры анимаций и интерактивных состояний: перемещение и масштабирование кнопки назад, наведение и нажатие разделов и переключателя языка, фокус, подъём кнопки связи и смещение стрелки. Зелёный блик повторяется каждые 3.1s с исходной кривой cubic-bezier(.35,.05,.22,1). Тайминги переходов сверены с вычисленными стилями исходной страницы Travel.

Названия разделов и якоря сохранены для каждого проекта. Например, в документах остаются «Обзор / Договор / Ордер», в Travel — «Обзор / Концепция / Экраны».

На узких экранах панель остаётся в один ряд. «Связаться / Contact» и стрелка видны. Подпись / design practice скрывается; RZ. остаётся. Чтобы вместить длинные названия на ширине 320px, используются более плотные мобильные размеры и отступы; анимации сохраняют исходные тайминги.

## Готовый код

- `assets/project-navigation.css` — изолированные стили панели и анимации.
- `assets/project-navigation.js` — единая логика якорей, активного раздела и кнопки назад.
- `assets/case-runtime.js` — меню языка и способов связи, сохранённые из v194; прежний общий scroll spy из этой копии удалён.
- HTML панели находится в каждом кейсе внутри `#rz-case-header`. Состав одинаков, переводы и цели ссылок соответствуют проекту.

`assets/site.js`, `assets/site.css`, `assets/contact-widget.css`, `assets/language-init.js`, `assets/language-picker.css` и `assets/case-translations.js` не изменены. Страницы проектов подключают отдельный case-runtime.js вместо site.js, поэтому главная использует прежнюю реализацию.

## Установка

Для полной готовой версии распакуйте архив v195 и используйте его папку целиком, сохраняя структуру assets. Откройте index.html или запустите локальный веб-сервер из папки сайта:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000/ .

Для переноса только изменений на существующую v194 скопируйте три новых файла assets выше и замените 11 HTML-файлов: hyundai, lato, travel, perfume, documents, chinaway, mdr, whoosh, petday, dreams, xflow. Главную index.html и прежние общие файлы заменять не требуется.

Подключения на страницах проектов уже настроены:

```html
<link rel="stylesheet" href="assets/project-navigation.css?v=195">
<script src="assets/project-navigation.js?v=195" defer></script>
<script src="assets/case-runtime.js?v=195" defer></script>
```

Для нового кейса скопируйте HTML-блок #rz-case-header из любого проекта и задайте свои ссылки. Например:

```html
<a class="rz-link travel-link" href="#process"
   data-ru="Процесс" data-en="Process">Процесс</a>
```

Если английский контент расположен в отдельном разделе, укажите его цель:

```html
<a class="rz-link travel-link" href="#case-process"
   data-target-en="#case-process-en"
   data-ru="Процесс" data-en="Process">Процесс</a>
```

Для существующих кейсов сохранены совместимые классы и ID, нужные их переводчикам. Не подключайте одновременно site.js и case-runtime.js и не добавляйте второй обработчик активных разделов. В готовой сборке подключения уже приведены к одному экземпляру.

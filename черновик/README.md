# UX/UI Portfolio

Статический сайт-портфолио с интерактивной веб-демонстрацией Drive&Deal.

## Структура

- `index.html` — главная страница портфолио.
- `hyundai.html` — кейс «Автосалон Drive&Deal».
- `drive-deal-preview.html` — интерактивная демонстрация приложения.
- Остальные HTML-файлы — страницы других кейсов.
- `assets/` — стили, скрипты, изображения и видео, необходимые страницам.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте localhost:8000. Для публикации статического сайта можно использовать GitHub Pages или Netlify.

## Ветки

- `main` — стабильная опубликованная версия.
- `develop` — рабочая ветка для изменений.

Сначала вносите изменения в `develop`, после проверки переносите их в `main`.

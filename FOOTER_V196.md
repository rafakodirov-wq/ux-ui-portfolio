# Единый футер · v196

Нижняя полоса с подписью RZ. / design practice и кнопкой «Наверх» установлена на главной и всех 11 страницах проектов. Источник размеров, кнопки, шеврона, анимаций и состояний — X’FLOW GYM из v195. Завершающие содержательные блоки с заголовками, выводами и описаниями сохранены отдельно.

## Точные параметры эталона

| Параметр | Десктоп, больше 700px | Мобильный режим, до 700px включительно |
| --- | --- | --- |
| Ширина полосы | 100%, максимум 1100px | 100%, максимум 1100px |
| Padding: верх / бока / низ | 36 / 24 / 56px | 24 / 18 / 35px |
| Внешний отступ сверху и снизу | 0 | 0 |
| Высота полосы | 147px | 108px |
| Высота кнопки | 54px | 48px |
| Padding кнопки | 13px 23px | 11px 17px |
| Размер шеврона | 19 × 19px | 19 × 19px |

Плавный скролл скопирован из X’FLOW GYM: `scrollTo({top:0,behavior:'smooth'})`. Шеврон повторяет исходные keyframes v191Chevron: от translateY(2px) до translateY(-3px), 2.1s ease-in-out infinite. Наведение поднимает кнопку на 4px; нажатие масштабирует до .97; клавиатурный фокус — обводка #168f85 толщиной 3px с отступом 4px. Параметры transition, градиент, размытие и тени сохранены по эталону.

Унифицирован именно внешний отступ самой полосы от предыдущего блока. Внутренние отступы содержательных блоков с выводами не изменялись.

## Код и установка

В готовом архиве всё уже подключено. Для установки распакуйте папку сайта, сохраняя структуру assets. Можно открыть index.html или запустить в папке сайта локальный сервер:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000/ .

Изменения к v195: обновлены index.html и 11 HTML-файлов кейсов; добавлены только два файла — assets/site-footer.css и assets/site-footer.js. Прежние файлы assets сохранены без изменений.

Общие подключения на каждой странице:

```html
<link rel="stylesheet" href="assets/site-footer.css?v=196.3">
<script src="assets/site-footer.js?v=196.3" defer></script>
```

HTML полосы:

```html
<footer id="rz-site-footer" class="portfolio-top-end">
  <span class="footer-signature">RZ. / design practice</span>
  <button class="portfolio-top-btn" type="button">
    <span data-ru="Наверх" data-en="Back to top">Наверх</span>
    <svg aria-hidden="true" fill="none" stroke="currentColor"
         stroke-linecap="round" stroke-linejoin="round" stroke-width="2"
         viewBox="0 0 24 24">
      <path d="m6 14 6-6 6 6"/>
    </svg>
  </button>
</footer>
```

Полоса должна находиться непосредственно в body, после основного контента и завершающего содержательного блока. Она не вкладывается в ограничивающий контейнер .wrap или внутрь блока выводов. На каждой странице должна оставаться одна такая полоса. При ручной замене сохраните ID прежней кнопки, если он используется существующим кодом кейса; в готовой сборке эти ID уже сохранены.

CSS изолирован по #rz-site-footer, поэтому прежние локальные правила футеров не меняют размеры новой полосы. JS синхронизирует подпись с текущим html lang, выполняет один скролл по клику и предотвращает повторное срабатывание старых обработчиков.

При появлении полосы плавающая кнопка связи временно поднимается, если иначе она перекрывала бы «Наверх». После ухода из футера её исходная позиция восстанавливается. Размеры и положение самой полосы и кнопки «Наверх» при этом остаются эталонными.
